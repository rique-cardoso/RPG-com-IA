Desenvolvimento de um jogo RPG utilizando Inteligência Artificial para gerar a história, cenários e decisões do jogo.

---

## 📖 Sobre
O **RPG com IA** nasceu da evolução de um projeto anterior, o meu primeiro sistema básico de programação e desenvolvimento web. Na versão antiga, a história e os cenários eram estáticos, exigindo milhares de linhas de código para controlar a lógica e a renderização a cada escolha do jogador.

Com a inteligência artificial, o jogo ganhou dinamismo: é possível explorar qualquer enredo e variar os contextos, garantindo que duas partidas com a mesma configuração inicial tenham desfechos completamente diferentes. O melhor de tudo é que isso dispensa milhares de linhas de código. O fluxo agora se resume a padronizar as respostas da IA, definir as condições de fim de jogo e renderizar as telas de forma simples e eficiente.
